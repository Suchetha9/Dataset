
# SDNIoTBot Dataset

This repository contains the **SDNIoTBot Dataset**, intended for research in:
- IoT Botnet Detection
- Software Defined Networking (SDN)
- Network Security
- Machine Learning and Deep Learning

## Dataset Download
The dataset is available here:
https://drive.google.com/file/d/1N2QLDPb90XOdxcuQ_Fb7ZSVOG4J3w_zY/view

## Repository Contents
- `FinalModel.ipynb` – Model training and evaluation
- `FCNNcontroller.py` – SDN controller implementation
- `mycontroller.py` – Custom SDN logic

## Applications
- Intrusion Detection Systems
- SDN-based Security Frameworks
- Academic and Research Use
